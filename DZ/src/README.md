
# PhoneBook
Простое приложение на Python для управления контактами

# Описание
Приложение позволяет создавать, редактировать, удалять и сохранять телефонные
контакты.

# Использование
Для начала необходимо открыть телефонный справочник выбрав меню (1) "открыть
файл", Это позволит подгрузить (phonebook.txt) находящийся в той же папке, 
что и программа. Далее работаем с файлом, и если хотим сохранить все введенные
изменения перед выходом из программы, необходимо выбрать меню (2) "Сохранить 
файл", и только после этого выходить, во избежания потери данных.
